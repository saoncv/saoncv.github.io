# Personal Academic Website - Prof. Dr. Saon Crispim Vieira

Personal academic and professional website built inspired by Bernat Font (TU Delft) minimal academic style.

## Deployment to GitHub Pages

1. Create a repository on GitHub named `saoncv.github.io` (or your preferred repository name).
2. Push the contents of this folder:

```bash
cd ~/saon_dev/saoncv.github.io
git init
git add .
git commit -m "feat: initial academic website release"
git remote add origin https://github.com/saoncv/saoncv.github.io.git
git branch -M main
git push -u origin main
```

3. Your website will be live automatically at `https://saoncv.github.io`!
